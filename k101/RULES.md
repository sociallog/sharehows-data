# 101 × How To Seoul 유튜브 번호 규칙 (2026-11-24, 대표 요청)

## 1. 번호는 하나: 101 번호
- 기준은 101 페이지의 이야기 번호(#001~#101)다. 유튜브 시리즈 회차(HOW TO 03, EP.03 같은 것)는 화면·제목·썸네일에 쓰지 않는다. 시리즈 이름(HOW TO, Seoul Info Report, Seoul Spots)은 그대로 써도 된다.

## 2. 영상 코드: `Seoul 101 · 001-3`
- `001` = 101 이야기 번호, `-3` = 그 번호에 붙은 영상 중 세 번째(올린 순서).
- 한 번호에 쇼츠·롱폼이 몇 개든 붙을 수 있다. 롱폼도 같은 순번을 쓴다.
- 한번 준 코드는 바꾸지 않는다. 영상을 내려도 번호는 비워 둔다(재사용 안 함).
- 101과 상관없는 영상(지도 소개 등)은 코드를 달지 않는다.

## 3. 어디에 표시하나
| 위치 | 표시 |
|---|---|
| 썸네일 | 오른쪽 위 작은 배지 `101 · 001` (순번은 생략) |
| 영상 첫 화면 | 시리즈 이름 옆에 `Seoul 101 · 001` |
| 제목 | 번호 넣지 않음 (검색용 제목 유지) |
| 설명란 첫 줄 | `📘 Seoul 101 · 001-3 → https://www.sharehows.com/korea-first-trip-101/#s001` |
| 101 카드 | 그 번호의 영상 전부 (대표 영상은 화면에 넣고, 나머지는 버튼) |

## 4. 동기화 (자동 + Claude 담당)
- 대장: `k101/videos.json` (영상 → 코드), `k101/registry.json` (101 카드에 실제로 있는 영상, stories.json에서 생성).
- 자동 확인: GitHub Action이 20분마다 채널 RSS를 읽어 `k101-sync.json`(data 브랜치)에 결과를 남긴다.
  - `give_code` 새 영상인데 코드가 없음 → Claude가 다음 순번을 주고 대표에게 설명란 문구 전달
  - `add_to_101_card` 코드는 있는데 101 카드에 영상이 없음 → Claude가 101에 넣음
  - `fix_youtube_label` 설명란에 코드가 없거나 다름 → 설명란 문구 전달(유튜브 수정은 PC 세션)
  - `not_linked` 101과 무관하거나 새 이야기 후보 → 대표에게 물어봄
- 101을 고칠 때마다: `python3 scripts/k101_registry.py /mnt/project-files/korea-101` 후 커밋.
- 규칙을 바꿀 땐 이 문서부터 고친다.
